# Table notes

## Table 16

Note: Cumulative Positive Excess sums annual values over analyzable years and is used to rank candidates. Only pairs with positive values in at least 10 years are included; this does not establish pairwise significance, execution order, or causality. The positive-year count measures repeated annual calculation results, not independent documents or incidents. A single multiyear report can contribute relations to several years. For Table 16, positive years are counted using Positive Excess > 10⁻¹² to exclude floating-point residuals; this is a numerical reporting tolerance, not a significance criterion. Source: prespecified S0 Positive Excess outputs; file identifiers are provided in the Supplementary Material. 

The CSV column heading uses Unicode superscripts for `10⁻¹²`. In the
verification code, the same threshold is written as `1e-12`. Cumulative and
peak values use the unchanged full-precision annual values.
