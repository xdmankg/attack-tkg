# Coverage of this release

Included inputs support numerical reproduction from adopted document–Technique
mappings and frozen event-time assignments. Original source-text extraction,
manual reading and the initial collection process are outside the executable
scope of this release. Reports and long quotations are not redistributed.

| Item | Coverage |
|---|---|
| Canonical identity | Complete retained 1,856-document canonical manifest and 2,192-row raw mapping. The earlier 2,269-file collection inventory is not included. |
| Source locations | Raw IDs, canonical IDs, relative repository paths, checksums, evidence positions and verified collection-level repository URLs. Original document URLs, historical retrieval dates and revisions remain unavailable. |
| Observed annual graphs | Reconstructed and checked for all 22 years and all 28,195 relation columns. |
| Follow-up annual null expectations | All 15 scenario/bundle foundation files with all three intensities included. One small annual ensemble was also rerun during packaging. |
| Initial bootstrap | Saved deterministic replay plus original numerical function; every value reproduced in the checked environment. |
| Follow-up inference | All stored summary tables and conditional null arrays; numerical replay commands for any of the 49 registered datasets. |
| LOTO | Raw descriptor inputs, losses, scalers, summaries, settings and seeds. Large redundant per-component predictions and float32 resampling arrays omitted; baseline losses and CIs regenerated. |
| Figures | All 11 final embedded images. Numerical redraw code for 3 and 5–10. Final matching vector sources for 1, 2, 4 and 11 were not located. An earlier Figure 11 SVG has different layout and proportions and is not substituted for the final image. |
| Tables | All 27 manuscript tables as text CSVs, alongside retained full-precision results where available. Math typography is flattened in the CSV transcriptions. |
| Operational validation | Proposed schema and schematic workflow only. No completed host/session validation or measured detection-rule performance is claimed. |

The artifact index distinguishes `conceptual`, `data-backed`, and
`transcription-with-partial-input-coverage` items. An indexed table does not imply
that every upstream data-collection statistic has been independently regenerated.
The package must not be described as providing a complete source-PDF-to-paper
rebuild or a fully recoverable collection snapshot.
